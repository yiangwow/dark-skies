# ALIEN SKIES

A single-player first-person breakcore movement-shooter. Gurren Lagann energy,
Ultrakill / Echo Point Nova movement: grapple planets, zip through space,
rocket-jump off worlds, over a neon stage suspended inside a giant gyroscope of
light. Heading toward mission-style speedrun-score levels where combat is the
score and the music is the multiplier (ADR-004 in `CLAUDE.md`).

Built in **Unity 6 (6000.5.1f1, URP)**. Everything visible is procedural —
the planets, the skybox, the arena, the weapons, the explosions, the music
mix — driven by code and one five-color palette. Zero store assets (ADR-004).

> Repo history note: the repo is named `dark-skies` for historical reasons;
> the game is Alien Skies (ADR-001 in `CLAUDE.md`).

## Play

Run `Builds/AlienSkies.exe`.

| Input | Action |
|---|---|
| WASD + mouse | Move / look (quake-style air control) |
| Space | Jump — **on a planet's surface it launches you along the normal** |
| F (hold) | Grapple (green `[+]` crosshair = valid anchor; release to fling) |
| RMB | Zip — straight-line flight to the grapple anchor (3s cooldown) |
| LMB | Fire |
| 1 / 2 / 3, scroll | Rocket / Rifle / Shotgun |
| B | Spawn/despawn the practice bot |
| Esc | Toggle cursor lock |

**The run:** you spawn at the start line; the clock starts the moment you
move. Follow the **amber beacon pillar** to the gate and touch the ring to
finish. Six magenta drones guard the route — kills score through the music:
the hotter the mix, the higher your multiplier (x1–x4). Under par time earns
a bonus; the grade screen ranks you D → S and keeps your best per sphere.
Death or falling into the void restarts the run instantly (enemies reset
with you). **B** spawns a practice bot at the start line, before a run.

The Gyroscope itself is watching — **the Voice of the Machine** taunts your
deaths, sneers at your D ranks, and recalculates when you earn an S.

**Two spheres** — press **TAB at the start line** to switch:
| Sphere | Identity | Par |
|---|---|---|
| 1 — THE CROSSING | across the Gyroscope to the far perch | 90 s |
| 2 — THE CLIMB | up the launch planets to a gate floating over the high worlds | 75 s |
| 3 — THE PLUNGE | dive from the high worlds down and across to Sphere 1's start | 60 s |

**Soundtrack:** drop `.ogg`/`.wav` files into
`Builds/AlienSkies_Data/StreamingAssets/Music/` — streamed at runtime,
shuffled; the mix intensity follows the fight. Masters kept in
`C:\Users\computer\Music\AlienSkies` are auto-installed by the build script.

## Development loop (WSL, editor CLOSED)

```bash
bash tools/run_tests.sh        # headless EditMode suite (~2 min)
bash tools/build_player.sh     # Windows player -> Builds/ (+ music restore)

# rebuild the generated scene (also via editor menu "AlienSkies"):
"<Unity.exe>" -batchmode -quit -projectPath "C:\Users\computer\My project" \
  -executeMethod AlienSkies.EditorTools.PlaygroundBuilder.BuildNeonVector

# verification screenshots -> TestResults/shot_*.png:
"<Unity.exe>" -batchmode -quit -projectPath "C:\Users\computer\My project" \
  -executeMethod AlienSkies.EditorTools.SceneScreenshot.Capture
```

## Where things live

| Path | What |
|---|---|
| `Assets/AlienSkies/Scripts/` | All gameplay code — pure-C# cores + thin MonoBehaviour glue |
| `Assets/AlienSkies/Tests/` | EditMode tests (every core is covered) |
| `Assets/AlienSkies/Editor/` | Scene generator, screenshot tool, player builder |
| `Assets/AlienSkies/Shaders/` | The whole art direction: 7 hand-written shaders |
| `Assets/AlienSkies/Config/` | Tuning ScriptableObjects (feel numbers, no recompile) |
| `docs/ARCHITECTURE.md` | Full architecture + every hard-won gotcha |
| `CLAUDE.md` | AI session entry point: resume state, ADRs, diary |

## The rules of this codebase

1. Game feel lives in **pure C# classes** with unit tests; MonoBehaviours stay thin.
2. Scenes are **generated by code** — never hand-edit `MovementPlayground.unity`.
3. Feel numbers live in **Config assets** — and their C# defaults + tests move together.
4. **Asset policy:** buy content, adopt infrastructure, build the feel ourselves.
5. Read `docs/ARCHITECTURE.md` before touching the motor, prefabs, or the builder.
