## What this is

The Unity home of **Alien Skies** — a first-person cosmic-scale movement/action game (Gurren Lagann feel; Ultrakill / Echo Point Nova movement). Gameplay is built here; the UE5 project at `E:/projects/AlienSkies/` remains the visual R&D home (black hole shaders, mech pipeline). Historical name of this repo: dark-skies.

## Conventions

- **Read `docs/ARCHITECTURE.md` first when touching networking, prefabs, the builder, or shaders** — max-detail systems map + every hard-won gotcha (prefab trio, FishNet patches, stacked-merge procedure, snapshot rule). `README.md` is the human-facing overview (controls, quick start).
- **Architecture:** movement/gameplay math in plain C# classes (`Assets/AlienSkies/Scripts/`), unit-tested in EditMode (`Assets/AlienSkies/Tests/`). MonoBehaviours stay thin. Tuning numbers in ScriptableObjects (`Assets/AlienSkies/Config/`).
- **Tests:** `bash tools/run_tests.sh` from WSL (Unity Editor must be closed). All movement math changes need a test.
- **Scenes:** generated by editor scripts in `Assets/AlienSkies/Editor/` where practical (rebuildable, reviewable).
- **Git:** author the owner's git identity, no Co-Authored-By. Feature branches + PRs, never push main. Commit `.meta` files always.
- **Legacy:** `Assets/Scripts/` + `Assets/Scenes/SampleScene.unity` are the June black-hole spike — leave unless asked.
- **Division of labor:** Claude writes C#/tests/tools and verifies headless; user drives the editor, playtests, and gives feel verdicts in vibe words (translate vibe → mechanics, explain changes before making them).

## ADRs

### ADR-001: Build the game in Unity; UE5 stays visual R&D (2026-07-03)
- **Status:** accepted
- **Context:** Six months of UE5 produced strong visuals but no gameplay. UE5's binary assets (Blueprints, levels) resist AI-driven iteration; Unity's C# + text scenes + headless CLI let Claude own the write→test→build loop.
- **Decision:** Gameplay is built in this Unity project, gameplay-first (graybox before art). The UE5 project is not abandoned — it remains the look-dev home and its art direction feeds back in later.
- **Consequences:** Feel work must be provable in tests + playtests, not screenshots. Product renamed "Alien Skies"; repo keeps its dark-skies name.

### ADR-002: Kinematic controller with pure-C# core (2026-07-03)
- **Status:** accepted
- **Context:** Movement shooters fight Rigidbody/PhysX for feel (air control, crisp stops, tunneling).
- **Decision:** `CharacterController.Move()` driven by hand-rolled velocity math in `MovementCore` (plain C#, Vector3/Mathf only). Quake-lineage accel model; zip-grapple (pull + 100% momentum on release); soft speed cap (drag past comfort speed, no hard ceiling).
- **Consequences:** The entire movement model is unit-testable headlessly; collision response is manual (`ClampAgainstSurface` on controller hits).

### ADR-003: Fish-Net networking from day one of combat (2026-07-04)
- **Status:** superseded by ADR-004 (2026-08-28)
- **Context:** End goal is Gurren Lagann × STRAFTAT × Quake 1v1 PvP. Building combat offline first risks a costly retrofit — fast-movement netcode needs server authority + client-side prediction baked into the simulation's shape. Quake's own source (GPL, C) is unusable here; its ideas live on in Unity libraries.
- **Decision:** Adopt Fish-Net (free, open source, prediction built in) before any combat code. All gameplay simulation stays in pure-C# tick cores (`MovementCore`, upcoming `CombatCore`) — exactly what prediction re-simulates — with thin NetworkBehaviour glue. Combat ships networked from its first commit.
- **Consequences:** Every combat feature is built/tested against the networked path (slower per feature, no rewrite later). Multiplayer behavior is verified by playtest with two local instances, not EditMode tests. Lag compensation deferred (LAN-first). Full milestone spec: `docs/superpowers/specs/2026-07-04-first-blood-design.md`.

### ADR-004: Single-player pivot; zero store assets (2026-08-28)
- **Status:** accepted — supersedes ADR-003 (Fish-Net) and the First Blood PvP direction
- **Context:** User verdict: an online game is too much — the networking tax (prediction, SyncVar glue, two-instance playtests) made every feature expensive and the game feel unreachable. Reference found: CICADAMATA (single-player freeform speedrun-score FPS levels). Separately: "I hate those prebought assets" — every pack fought the identity and needed surgery (URP conversion, hue rotation, abandonment), while everything hand-written (NeonPlanet/NeonRim/procedural explosions) won its playtests.
- **Decision:** Single-player mission-style breakcore movement-shooter. FishNet and all networked glue removed; pure-C# cores stay, thin local MonoBehaviour drivers. **All store asset packs removed; all visuals are code** (hand-written shaders, code-built meshes, palette coherence). MusicCore heat becomes the score multiplier — the user's breakcore is the scoring spine.
- **Consequences:** ~20 PRs of movement/combat/juice feel carry over untouched at the core layer; the prefab-trio rule and FishNet patch maintenance die; Tirgames/Hovl/SGT/CW/Vefects deleted (re-importable from Asset Store if ever needed); MatchCore → RunCore. Full spec: `docs/superpowers/specs/2026-08-28-singleplayer-pivot-design.md`.
